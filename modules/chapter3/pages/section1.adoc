= Making Target Environment Ready

- Log in to the *bastion* host using the credentials from the RHDP portal.

video::aap2.6_container_install.mp4[align="left",width=800,height=500]

- Copy the migration artifact files to `container.lab` using `scp`:
+
[source,bash,role=execute]
----
scp migration_artifact.tar container.lab:/home/lab-user/
scp migration_artifact.tar.sha256 container.lab:/home/lab-user/
----

- Install the required and useful utilities:
+
[source,bash,role=execute]
----
ssh container.lab 
----
+
[source,bash,role=execute]
----
tar xf migration_artifact.tar
sudo dnf install -y wget git-core rsync vim ansible-core
----
 
*Prepare the Containerized Setup*

- Go to the https://access.redhat.com/downloads/content/480/ver=2.6/rhel---9/2.6/x86_64/product-software[Installer,window=_blank] link and copy the download URL for *Ansible Automation Platform 2.6 Containerized Setup Bundle*.
+
NOTE: Complete this step and the next step in sequence to avoid URL expiration errors. Reload the page to get a fresh link if the download fails.

. Download the installer file to the VM: 
+ 
[source,bash,role=execute]
---- 
 wget -O aap.tar.gz "<paste-link-here taken from step 3>"
----

. Extract the *aap.tar.gz* file using the following command:
+ 
[source,bash,role=execute]
---- 
 tar -xvf aap.tar.gz
----

. Using the *cd* command, enter the extracted folder. Then, use the *vim* command, open the *inventory-growth* file and make the following changes, wherever they appear throughout the entire *inventory-growth* file:
+ 
[source,bash,role=execute]
---- 
 cd <extracted-folder-from-step-6>
 vim inventory-growth

aap.example.org -> container.lab

<set your own> → redhat

<set your own> ← This value can be customized as per your need but remember to use the same while doing the login after the deployment. 
----
+
Note: Please click this link to learn how to use https://www.geeksforgeeks.org/basic-vim-commands/[Vim basic operations,window=_blank] and also to remove any node under `[automationeda]`. 

. Once the inventory file is ready, run the following command to start the installation:
+
[source,bash,role=execute]
----
ansible-playbook -i inventory-growth ansible.containerized_installer.install -e @../migration_artifact/secrets.yml -e "__hub_database_fields='{{ hub_db_fields_encryption_key }}'" 
----
+
[NOTE]
====
 The preflight check might fail for ansible_version. You can ignore this error and continue with the installation by commenting the task or adding the version installed on the your systems. 
 
 The path of the file is: ansible-automation-platform-containerized-setup-bundle-2.6-14.2-x86_64/collections/ansible_collections/ansible/containerized_installer/roles/preflight/tasks/core.yml
====


. Use the *admin* user and the password set during installation (set to *redhat* in the video above).
+
NOTE: Use a stronger password in an enterprise deployment.

. Attach a Red Hat subscription to activate AAP. You can use a 60-day trial subscription, a *Red Hat Developer Subscription for Individuals*, or a manifest file.

. After logging in, run a *Project sync* on the *Demo Project* to confirm that jobs execute successfully.
